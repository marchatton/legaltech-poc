Key decisions

ADR-01 Evidence-first: every claim backed by citation IDs and snippet hashes
ADR-02 Fail-closed: unverifiable citations block export by default
ADR-04 Hybrid retrieval: lexical (tsvector) + semantic (pgvector), returns chunk IDs
ADR-05 Durable orchestration: side effects in retryable, idempotent steps
ADR-15 Deterministic chunking: page-bounded, max 20 lines / 1500 chars, overlap 4
ADR-17 Verification is integrity-only (v1): schema + hash, no entailment model
