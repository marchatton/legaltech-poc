Components

Accordion

Citation verification checks that every extracted commitment can be traced back to a specific location in the source documents. It matches text snippets with page coordinates and validates the evidence chain.
When a citation fails, the commitment is flagged as "Citation failed" and cannot be exported until resolved. You can retry verification, manually review the evidence, or mark it as reviewed with a note.
Upload the referenced document or mark the commitment as reviewed. Orbital will display "Not found in provided documents." when evidence is missing — this is by design, not an error.
