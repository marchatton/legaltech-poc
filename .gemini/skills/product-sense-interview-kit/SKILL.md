# Product Sense Interview Kit

## When to use
Trigger this skill when asked to:
- Design product sense interviews, exercises, and scoring
- Create a question bank by component
- Write interview feedback from notes/transcripts

## Inputs to collect
- Role level and product context.
- Which components matter most (empathy, creativity, domain, taste, strategy).
- Interview constraints (time, format, panel).

## Workflow
1) Define signals
   - Choose which components to test and how.
   - Separate product sense scoring from communication scoring.

2) Assemble interview plan
   - Select 1–2 questions per targeted component.
   - Add follow-ups that probe assumptions, trade-offs, and user simulation.
   - Use references/interview-framework.md.

3) Design exercises (optional)
   - Keep each exercise singularly focused.
   - Prefer multiple small exercises.
   - Define “what good looks like” in plain language.

4) Run and record
   - Capture raw notes and key quotes.
   - Score immediately after each section.

5) Write feedback
   - Use assets/feedback-template.md.
   - Provide component scores, confidence, and hire/no-hire reasoning.

## Output artefacts
- Question bank
- Scorecard
- Exercise brief(s)
- Feedback write-up
