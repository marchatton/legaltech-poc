# Product sense interviewing toolkit

## Component scoring
Separate product sense components from communication.

Test at minimum:
- Cognitive empathy
- Creativity

Optionally test:
- Domain knowledge
- Taste & UX
- Strategic thinking

## Best practices
- Build a question bank.
- Ensure interviewers have strong product sense.
- Listen closely and probe with follow-ups.
- Assign separate component scores.
- Write feedback clearly.

## Feedback format
Summary → Context (optional) → Questions → Raw transcript → Score immediately.
