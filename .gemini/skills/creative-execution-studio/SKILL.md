# Creative Execution Studio

## When to use
Trigger this skill when asked to:
- Generate and refine novel solutions to a product problem
- Run a structured ideation session and produce viable options
- Find differentiated approaches and stress-test them

## Inputs to collect
- Problem statement and constraints.
- Target segment and job.
- Success metric(s) and guardrails.
- Known alternatives/competitors (optional).

## Workflow
1) Frame the brief
   - Write one-sentence problem statement.
   - Define constraints and non-goals.
   - Define success metrics.

2) Generate idea volume first
   - Produce 15–25 raw ideas before narrowing.
   - Rotate through techniques in references/creativity-techniques.md.

3) Capture each idea as a mini card
   - Hook:
   - User value:
   - What makes it uncommon:
   - Which adoption lever it targets (M/F/S/N):

4) Narrow and sharpen
   - Pick top 3–5 using: adoption impact, differentiation, feasibility, speed to learn.
   - Write concept briefs (assets/concept-brief-template.md).

5) Stress-test
   - Run pre-mortems (assets/premortem-template.md).
   - Identify nth order effects and incentives.
   - For B2B, test against the null hypothesis.

## Output artefacts
- Idea backlog
- 3–5 concept briefs
- Pre-mortem + risks + recommended tests
