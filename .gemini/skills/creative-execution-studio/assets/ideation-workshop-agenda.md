# Ideation workshop agenda (75–90 mins)

## 0) Setup (5)
- Restate problem, constraints, success metrics.
- Assign one facilitator and one scribe.

## 1) User + job grounding (10)
- State target segment, job, struggling moment.
- List current alternatives.

## 2) Idea volume (20)
- Generate 15–25 ideas.
- Rotate techniques every 3–4 mins.

## 3) Cluster + name (10)
- Group ideas into themes.
- Name the themes.

## 4) Narrow (15)
- Vote to select top 3–5 ideas based on adoption impact + speed to learn.

## 5) Concept briefs (15)
- Write mini concept briefs for finalists.

## 6) Stress-test (10)
- Pre-mortem and nth order effects.
- Decide next tests.
