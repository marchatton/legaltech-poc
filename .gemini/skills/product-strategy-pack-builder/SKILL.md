# Product Strategy Pack Builder

## When to use
Trigger this skill when asked to:
- Create positioning, segmentation, and differentiation
- Build a market map and B/T/D decisions
- Write a strategy one-pager with pillars and trade-offs

## Inputs to collect
- Product stage (explore/expand/extract).
- Current vision or direction (even if rough).
- Competitive set and alternatives.
- Constraints and GTM context.

## Workflow
1) Draft internal positioning
   - Define where to play and the macro problem solved.
   - List competitors and alternatives without vanity 2x2s.

2) Build segmentation
   - Propose 2–4 segmentation dimensions.
   - Apply pre-qualifiers and the 5 tests from references/strategy-core.md.

3) Prioritise segments
   - Create P0/P1/P2 and explicit non-targets.
   - Add bias checkers: speed to differentiate, reachability, expansion path.

4) Create a market map and B/T/D
   - Define strategic themes.
   - Rate competitors for priority segment(s).
   - Decide Below/Tablestakes/Differentiate per theme.

5) Define differentiation pillars
   - Choose 2–6 pillars grounded in needs, alternatives, unique assets, industry direction, creative choices.
   - Write explicit trade-offs and non-priorities.

6) Write the strategy one-pager
   - Use assets/product-strategy-one-pager-template.md.
   - Include metrics and recommended decisions/actions.

## Output artefacts
- Segment priority table
- Market map + B/T/D choices
- Strategy one-pager

## Bundled resources
