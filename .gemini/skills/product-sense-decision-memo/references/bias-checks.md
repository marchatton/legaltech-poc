# Cognitive biases in product usage (working shortlist)

## How to use this file
- Use as a bias scan when diagnosing usage/adoption problems.
- For each suspected bias, write: "What does the user believe?" → "What do they fear?" → "What default will they accept?"

## Commonly useful biases (starter set)
- Default effect / status quo bias
- Choice overload
- Loss aversion
- Framing effect
- Anchoring
- Social proof / bandwagon
- Availability heuristic
- Peak-end rule / duration neglect
- Present bias / hyperbolic discounting
- Sunk cost fallacy
- Confirmation bias
- IKEA effect
- Automation bias
