# JTBD Interview Sprint

## When to use
Trigger this skill when asked to:
- Figure out what customers are hiring the product for
- Design and run JTBD interviews properly
- Synthesize interviews into forces, timelines, and opportunities

## Inputs to collect
- Name the decision this research must inform.
- Define the target participant criteria.
- List suspected jobs and alternatives.
- Provide any existing notes or recordings summaries.

## Workflow
1) Set the research aim
   - Write the decision and uncertainty to reduce.
   - Define participant criteria (must include an active decision).

2) Build the interview plan
   - Write a screener (assets/recruiting-screener-template.md).
   - Draft an interview script (assets/jtbd-interview-script-template.md).
   - Use references/jtbd-toolkit.md for timeline + forces prompts.

3) Run interviews (or prepare to run)
   - Capture specific events and sequence, not opinions.
   - Probe trade-offs and alternatives.

4) Synthesize
   - Build a timeline per interview.
   - Extract pushes/pulls/habits/anxieties.
   - Cluster into themes and struggling moments.
   - Draft job statements as progress in a circumstance.

5) Translate into opportunities
   - Convert themes into opportunity hypotheses.
   - Link each opportunity to adoption levers (motivation/friction/satisfaction/nudges).

## Output artefacts
- Recruiting criteria + screener
- Interview script + notes template
- Synthesis doc (assets/jtbd-synthesis-template.md)
