# Product taste toolkit

## WAYRTTD
1) Describe current structure
2) Name problems being solved (and for whom)
3) Propose optimisations
4) Prioritise

## Solve with principles
- Draft principles
- Debate, cut, and stack-rank principles
- Generate option Z (beyond X vs Y)
- Choose based on which option satisfies top principles

## Taste components (starter)
- High standards
- Brand understanding
- Motivation theory understanding
- Cognitive empathy
- Strong intuition for the main problem (WAYRTTD)

## Grep hints for large docs
- `WAYRTTD`
