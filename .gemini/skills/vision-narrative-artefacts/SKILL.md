# Vision and Narrative Artefacts

## When to use
Trigger this skill when asked to:
- Write or refine a product vision narrative
- Draft a PRFAQ or a product proposal (Amazon 5Q)
- Turn strategy into artefacts people can execute against

## Inputs to collect
- Audience and purpose (alignment, funding, GTM, roadmap decision).
- Horizon (6 months, 1 year, multi-year).
- Strategy inputs if available (segments, pillars, constraints).

## Workflow
1) Anchor definitions
   - Keep mission/vision/strategy/segmentation/positioning/roadmap distinct.
   - Use references/product-artefacts.md.

2) Draft the vision narrative
   - Paint a vivid future state grounded in user jobs.
   - Avoid feature soup; tie each element to outcomes and pillars.

3) Draft the product proposal (5Q)
   - Use assets/product-proposal-template.md.

4) Draft the PRFAQ
   - Start with a press release that makes the value legible.
   - Add FAQs that force clarity on trade-offs, risks, metrics, and rollout.

5) Check comms clarity + measurement
   - Ensure messaging answers the four comms questions.
   - Add launch gates, leading/lagging metrics, and guardrails.

## Output artefacts
- Vision narrative
- Product proposal (5Q)
- PRFAQ (press release + FAQs)
- Metrics and launch gates section
